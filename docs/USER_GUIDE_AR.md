# دليل RoadCrack AI

1. ثبّت الحزم وشغّل الخدمتين وفق تعليمات README. اضبط `ROADCRACK_DETECTORS` على قائمة مفصولة بفواصل من أزواج الاسم والمسار. مثلاً `yolo26s=models/yolo26s-trained.pt`. للوضع المفصّل اضبط أيضاً `ROADCRACK_SEGMENTER` على ملف التقسيم المحدد من التحقق.
2. افتح لوحة التحكم، واختر تحليل الصور أو الفيديو. ارفع JPEG أو PNG أو WebP للصور، أو MP4 أو MOV أو AVI أو WebM أو MKV للفيديو، وفق ما تدعمه برامج الترميز المتاحة.
3. اختر وضع التحليل وحد الثقة. يُظهر الوضع السريع الصناديق والفئات. يُضيف الوضع المفصّل قناعاً ثنائياً على مستوى البكسل دون تصنيف نوع الشق لكل بكسل.
4. صدّر نتائج الصورة بصيغة JSON أو CSV أو PDF، ونزّل القناع إذا كان متاحاً. استخدم صفحة السجل لرؤية عمليات الجلسة الحالية.
5. اضبط أخذ عينات الفيديو ثم ابدأ التحليل. استخدم «تحديث الحالة» لمتابعة المهمة أو «إيقاف المعالجة» لإلغائها. نزّل الفيديو الناتج وسجل الإطارات JSONL. الفيديو الناتج صامت، وتظهر العلامات على الإطارات المحللة. مُعرّفات التتبع تقديرية، وقد يتغير المعرّف مع حركة الكاميرا أو الاحتجاب.
6. افتح «تقييم النماذج» لعرض ملف تقييم ناتج عن تشغيل `scripts/compare_runs.py` على مخرجات تجارب حقيقية.

حد الصورة 15 MiB و24 مليون بكسل. حد الفيديو 95 MiB و18 ألف إطار. قد يتجاوز الفيديو الطويل أو العالي الدقة هذه الحدود. تظهر رسالة عربية عند تلف الملف أو غياب الأوزان. يعمل التطبيق على CPU، وتتوقف سرعة التحليل على الجهاز، وحجم الملفات، والوضع المختار. النتائج مواضع بالبكسل ولا تُقدّر عرض الشق أو عمقه في الواقع.
