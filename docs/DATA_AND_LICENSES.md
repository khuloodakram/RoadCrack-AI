# Data and licenses

| Source | Evidence observed | Reuse conditions and remaining verification |
| --- | --- | --- |
| [RoadDamageDetector / RDD2022](https://github.com/sekilab/RoadDamageDetector) | Git and publisher README accessible. RDD2022 train images are JPEG with Pascal VOC XML. Official test images have no public XML in that archive. S3 archive and Figshare API probes returned proxy 403. | The repository LICENSE covers its code. Record the terms for the exact RDD2022 dataset release from its [deposit](https://figshare.com/articles/dataset/RDD2022_-_The_multi-national_Road_Damage_Dataset_released_through_CRDDC_2022/21431547) before use and credit Arya et al. The repository's later image license section does not establish the license for every release. |
| [CRACK500 source](https://github.com/fyangneil/pavement-crack-detection) | Git and README accessible. The Google Drive dataset endpoint returned proxy 403. The other published archive mirrors and exact mask encoding remain unverified. | Confirm data reuse terms and source-specific mask conventions. A source-code license is insufficient to establish dataset rights. |
| [DeepCrack](https://github.com/yhlleo/DeepCrack) | Publisher Git archive retrieved. Nested ZIP contains 300 train image/mask pairs and 237 test pairs. An inspected label was an 8-bit PNG with values 0 and 255. | Publisher restricts use to non-commercial research and education. Credit Liu et al. (2019). Preserve the official test groups when review confirms they are isolated. |
| [CrackForest](https://github.com/cuilimeng/CrackForest-dataset) | Publisher Git archive retrieved. It contains JPEG images and 118 MAT and SEG annotations. An inspected MAT sample had `groundTruth.Segmentation` values 1, 2 and a separate `Boundaries` field. | Non-commercial research only according to publisher README. Credit Shi et al. and Cui et al. Check foreground polarity against the source image before using the converter. |

All archives were kept outside Git. Scope of any intended commercial use and provenance of capture groups are open. For imported data, retain source URL, release, checksum, acquisition date, terms and attribution alongside each dataset version. Keep people's faces, plates, and location information subject to project privacy rules.

## Libraries and weights

- [PyTorch](https://github.com/pytorch/pytorch/blob/main/LICENSE) uses a BSD-style license. [Torchvision](https://github.com/pytorch/vision/blob/main/LICENSE) uses BSD-3-Clause. [segmentation-models-pytorch](https://github.com/qubvel-org/segmentation_models.pytorch/blob/main/LICENSE) uses MIT. Review encoder checkpoint terms independently, including ImageNet-derived weights. Hugging Face checkpoint metadata access returned proxy 403 here.
- [Ultralytics licensing](https://www.ultralytics.com/license) offers AGPL-3.0 and enterprise terms. The dependency is integrated into detection and the service. Before distributing the product or operating a network service, confirm applicable source-availability obligations or obtain appropriate enterprise terms. The three [official release checkpoints](https://github.com/ultralytics/assets/releases/tag/v8.4.0) loaded on CPU. Retain their specific terms with any derived checkpoints.
- FastAPI (MIT), Streamlit (Apache-2.0), OpenCV (Apache-2.0 for recent releases), ReportLab (BSD), and FFmpeg are used. Review the shipped FFmpeg build and codec terms if redistributing a container. The dependency list is pinned for the tested Linux CPU workflow; check the lock and container for licensing and security again before release.
- No application-wide license is asserted here. Confirm the intended licensing and deployment model before distribution.
